## Implementation Details

### AudioPlayerService
- Pure state management service for tracking which entry is playing
- Main process only (no actual audio playback in Node.js)
- Renderer process handles actual HTML5 <audio> playback via IPC
- Exports: AudioPlayerState interface, AudioPlayerService class, audioPlayerService singleton

### Key Methods
1. getState() - Returns current playback state
2. play(entryId, filePath) - Start playing an entry
3. stop() - Stop playback
4. toggle(entryId, filePath) - Toggle: stop if playing same, otherwise switch
5. isPlayingEntry(entryId) - Check if specific entry is playing

### Tests (9 total)

## Architecture Notes
- Main process: tracks state only via AudioPlayerService
- Renderer process: handles HTML5 <audio> element for actual playback
- IPC communication: PLAY_AUDIO, STOP_AUDIO channels defined in ipc-channels.ts
- Separation enables unit-testable main process without requiring audio libraries
