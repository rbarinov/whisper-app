## Changes Made

### 1. Dock Visibility Tracking (electron-app/src/main/main.ts)

- Added `openWindowCount` counter and `dockHideTimer` variable
- Added `updateDockVisibility(count: number)` helper function:
  - Guarded with `if (process.platform !== 'darwin' || !app.dock)` — safe on Windows/Linux
  - When count > 0: calls `app.dock.show()` to make app appear in Cmd+Tab
  - When count === 0: calls `app.dock.hide()` after 100ms delay (matches Swift reference pattern)
  - Clears any pending hide timer when a new window opens (prevents race conditions)
- Added `export function trackWindowForDock(win: BrowserWindow)`:
  - Increments openWindowCount and calls updateDockVisibility
  - Registers `win.on('closed')` handler to decrement count and update dock
  - Ready for use when Settings/History windows are implemented
- Moved initial `app.dock.hide()` from `createWindow()` to `app.whenReady()` handler
  - This is more correct: dock should be hidden at app startup, not per-window creation

### 2. App Name (electron-app/src/main/main.ts)
