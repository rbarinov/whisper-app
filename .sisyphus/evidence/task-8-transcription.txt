- Multipart built manually with Buffer.concat (NO FormData browser API)
- Retry: 3 attempts, delays [500, 1500, 3000]ms (from constants)
- Timeout: 60000ms (from WHISPER_TIMEOUT_MS constant)
- Retries on: 5xx, 408, 429, network errors
- NO retry on: 4xx (except 408/429), NO_API_KEY, INVALID_URL, DECODING_ERROR
- http vs https module selected based on URL protocol
